# PARK OKINAWA — 国際通り駐車場マップ

沖縄・那覇「国際通り」周辺の駐車場検索・運営サービス。**初期実装（MVP）**です。見た目だけのモックではなく、登録・ログイン・データベース保存・管理者審査・ポイント台帳が動きます。

## 実装してある機能

- **一般向け:** スマホ向けの駐車場一覧・絞り込み・地図（Leaflet / OpenStreetMap）、駐車場詳細、料金シミュレーター、公式出典リンク、Googleマップ住所検索
- **会員:** 登録、メールのリンク認証、ログイン、パスワード再発行、ニックネーム変更、メール変更・退会、投稿フォーム（写真添付）、投稿・ポイント履歴、特典交換申請
- **管理者:** 駐車場の追加・編集・公開設定、時間帯・24時間・当日・最大料金設定、計算プレビュー、投稿承認とポイント付与、会員へのポイント調整、特典交換処理、広告ユニットのID設定
- **公開ページ:** 仮の利用規約・プライバシーポリシー、robots.txt、sitemap.xml、ads.txt
- **セキュリティ:** Argon2ハッシュ、署名Cookie、CSRFトークン、権限チェック、ポイント取引時のSQLiteトランザクション、画像サイズと形式の検査・EXIF削除、管理監査ログ

## ローカルですぐ試す

Python 3.11以上で実行:

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py init
python manage.py seed
python manage.py admin
python -m uvicorn app.main:app --reload
```

ブラウザで <http://127.0.0.1:8000> を開く。管理者は `/login` → `/admin` へ。初期状態で**管理者パスワードは設定されていません**。`python manage.py admin` で自分で登録してください。

開発環境では SMTP が未設定の場合、会員登録の**確認メールURLがサーバーのターミナルに表示されます**。本番環境では SMTP 未設定でメール認証ができなくなるため、設定が必須です。

## サンプルデータについて

`data/test_parking_12.json` は、前の調査で集めた **タイムズ・三井のリパークの12件**。公式情報由来のテスト登録であり、現地確認は未実施です。住所の緯度経度は未確認のため、**地図の入口ピンは勝手に作成しません**。現地調査後、管理者編集画面で正確な入口位置を登録してください。

料金の自動計算は、**現地料金が検証されていない間は停止**してあります。管理画面で条件を確認し、料金計算プレビューを試してから「自動料金計算を公開する」をオンにします。

## 本番公開までの作業

1. HTTPSの独自ドメインとPythonアプリを動かすサーバーを用意する（通常の静的Webサイト無料ホスティングだけではバックエンドは動きません）。
2. 環境変数 `ENVIRONMENT=production`, `SECRET_KEY`（長いランダム値）, `SESSION_SECURE=true`, `APP_BASE_URL`, `DATABASE_PATH` を設定。
3. 永続ディスク・定期バックアップを用意。コンテナの一時ディスクにSQLiteや`uploads/`を置かない。複数インスタンスで運用する場合はPostgreSQLなどに移行。
4. `SMTP_HOST`, `SMTP_FROM`, `SMTP_USER`, `SMTP_PASSWORD` 等を設定して会員登録メールが届くことを確認。
5. 運営者情報・問い合わせ先・利用規約・プライバシーポリシー・ポイント交換条件を確定し、必要に応じて専門家確認。ページには仮内容と明記。
6. Amazonギフトカード等の手動送付は、取扱規約を確認し、別途安全なルートで行う。初期の交換受付はOFFです。
7. 同意管理（CMP）はこのMVPでは未実装。対象地域の利用者にGoogle広告配信する前に、Googleの要件に沿って導入する。
8. AdSenseを審査・設定し、管理画面でPublisher IDと広告枠IDを入力。設定前は広告は表示されません。
9. 本番公開前に負荷試験、認証周りのレート制限、アカウント削除、ポイント報酬の不正対策、ユーザー規約の法的確認を実施。

## 開発上の制限と注意

- 料金計算は初期版の**保守的な見積もり**。同時に重なり合う複数の最大料金条件や特殊な精算規約の解釈は「料金要確認」を返します。公式看板のルールを優先。
- 日本の祝日カレンダーは未連携。`weekend` は土日を表します。祝日や特別日は `special_dates` で個別に設定してから公開してください。
- 投稿承認はポイント付与のみ自動。投稿された文面をそのまま駐車場に反映せず、管理者が内容を照合して編集します（不正な投稿による書換え防止）。
- 公式データは少数サンプル。入口座標未設定の場所は地図にピンが出ません。
- メール・パスワード再設定の送信回数制限など、高度な不正利用対策は本番導入前に追加が必要。
- AdSenseの広告自動表示は設置できても、収益・審査の通過は保証されません。
- 利用規約・プライバシーポリシー・連絡先は仮実装。完成した規約としてそのまま公開しないでください。

## Windowsでの簡単な起動方法

1. ZIPを展開する。
2. Python 3.11以上がインストールされていなければインストールする。
3. `start_windows.bat` をダブルクリックする。初回は依存ライブラリをインストールするため時間がかかる。
4. 管理者は別のウィンドウで `create_admin_windows.bat` を実行する。
5. サイトを開く: <http://127.0.0.1:8000> 。管理者アカウントでログインして `/admin` へ。

macOS/Linuxでは `sh start_mac_linux.sh` で起動できる。
